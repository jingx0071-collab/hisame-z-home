# Coquette Atelier — 接入就绪版

法式复古浪漫主题素材，精细水彩手绘/剪贴画风。奶油白 + 裸粉主调，珍珠、蕾丝、蝴蝶结缎带、樱桃、玫瑰。

## 目录

| 目录 | 内容 | 张数 |
|---|---|---|

| `02_icons` | 蝴蝶结 / 心形 / 樱桃 / 珍珠 / 缎带（透明底） | 5 |
| `03_decorations` | 蕾丝分割线 / 缎带横幅 / 珍珠边框（透明底） | 3 |

## 与原始包的差异

- 珍珠边框、空首饰盒、茶杯信笺 3 张已完成**抠底**，现为真透明 PNG，可直接叠在任意底色上。原包的 `unprocessed_background` 子目录已移除。
- 全部透明素材四角与内部孔洞均已清理，主体完整无损。
- `manifest.json` 已更新为真实透明状态。

## 使用要点

- **图标**（1254×1254，偏大）：接入时按显示尺寸缩放；水彩细节较多，建议用于装饰性入口/卡片，功能图标在 24–32px 下先检查清晰度。
- **背景**（1024×1536 竖版）：手机端 cover 铺满。
- **装饰件**：等比放置，勿拉伸变形。
- **纹理**（`lace_tile` / `satin_tile`）：为 RGB 带自身底色，直接 `repeat` 铺排即可；若要把蕾丝叠到别的颜色上，需单独抠透明。
- **空状态插图**：透明底，直接置于卡片/空列表中央。

## 配色（palette.json）

| 语义 | 名称 | HEX |
|---|---|---|
| primary | 柔粉 | `#F8C8D4` |
| background | 奶油白 | `#FFF5F7` |
| secondary | 玫瑰金 | `#E8B4B8` |
| accent | 樱桃红 | `#D9455F` |
| dark | 酒红 | `#7B2D3E` |

> 插画整体以奶油白与浅粉为主，红色仅集中在樱桃等少量元素。接入配色变量时，主界面建议以 background/primary 打底，accent/dark 用于强调。
